# Alice

Рабочий проект жестокой 2D soulslike-метроидвании по «Алисе в Стране чудес» Льюиса Кэрролла. Название временное.

## Документация

- **[Открыть GDD в HTML](Docs/GameDesignDocument.html)** — единый документ с главами, полным сюжетом, поиском, темами оформления и печатью. Открывается в браузере без сервера и интернета.
- [Сюжетная основа — этап 1](Docs/NarrativeFoundation.md) — характер Алисы, выбранные правила истории, проверка мотивации и открытые решения.
- [Кампания по эпизодам — этап 2](Docs/CampaignEpisodes.md) — 44 эпизода с действиями игрока, переходами, обязательными возвращениями и последствиями.
- [Основная история](Docs/Story.md) — подробный сюжет от сада с сестрой до обрывка перед титрами, мотивы Алисы, причины боёв и освобождение страны.
- [Дизайн-документ всей игры](Docs/GameDesignDocument.md) — сюжет, пять биомов и боссов, способности, карта, боевая система, враги и рамки производства.
- [План разработки](Docs/DevelopmentRoadmap.md) — этапы от проверки управления до полной кампании.
- [Техническая настройка](Docs/TechnicalSetup.md) — версия Unity, сцены, ввод, структура и проверка проекта.
- [Происхождение контента](Docs/ContentProvenance.md) — первоисточники, собственные дополнения и учёт лицензий.

**Текущий этап — проработка сюжета на бумаге.** Техническая разработка приостановлена до согласования истории. По событиям и характерам актуальна `Docs/Story.md`; технические и системные предложения GDD пока остаются черновыми.

HTML собирается из семи Markdown-документов; правки вносим в исходные тексты и после изменения пересобираем HTML из корня проекта:

```powershell
pwsh -File ./Docs/Build-ReadingEdition.ps1
```

Нужен PowerShell 7, сторонних библиотек и сетевых запросов нет. Оформление находится в `Docs/Reader.template.html`. Кнопка «Печать» печатает выбранный документ; ссылки на главы можно сохранять и открывать напрямую.

## Запуск

1. Добавить эту папку в Unity Hub и открыть **Unity 6000.6.6f1**.
2. Дождаться импорта пакетов и компиляции.
3. Открыть `Assets/_Alice/Scenes/Prototype_Traversal.unity`.

Если стартовые сцены ещё не созданы, выполнить **Alice → Project → Configure Foundation**. Команда сохраняет существующие сцены; перед её ручным запуском сохранить собственные изменения.

Это фундамент проекта: URP 2D, структура ассетов, две стартовые сцены и схема ввода. Игровой контроллер, бой и контент кампании пока не реализованы. `Bootstrap` пока служит стартовой сценой; автоматической загрузки игрового мира ещё нет.

## Git

Храним `Assets` вместе с `.meta`, `Packages` вместе с lock-файлом, `ProjectSettings` и документацию. `Library`, `Temp`, локальные настройки, сборки и `work` исключены. Unity использует текстовую сериализацию и видимые `.meta`.

Коммиты и публикация выполняются отдельно по решению владельца проекта.
