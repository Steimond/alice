# Revision15 — бег Алисы, второй дубль

8 ноября 2026, сервис PixelLab, по просьбе владельца: «сама Алиса подёргивается, давай нормально анимацию сделаем, всё же перегенерим по всем правилам». 6 генераций.

## Почему переделывали

Старый бег (`Revision03/pipeline`, GDD 0.17) скакал по высоте: голова по кадрам 0, −2, −1, −3, +1, 0, 0, −4 px. Причина — в `runpose.ps1`: тело опускалось, пока нижняя ступня не касалась земли, и высота головы следовала за углами ног. Генератор выполнил позы честно, рывки были заложены в скелете. Сначала кадры полёта опустили на 2 px без генерации и убрали дрожание камеры (`CameraFollow2D`), но подёргивания самой Алисы остались.

## Позы

`run/runpose2.ps1` — 8 скелетов из длин костей стойки (`Revision03/pipeline/stand-skeleton.json`):

- таз идёт по заданной плавной кривой: касание — середина, подсед — на 1 px ниже, проход — середина, полёт — на 1,5 px выше; голова не наклоняется вместе с корпусом;
- ноги ставятся обратной кинематикой (бедро и голень, колено всегда вперёд) в заданные точки стоп; ступня на земле отъезжает назад ровно на шаг игры за кадр — 7 px (`RunFrameDistance` 0,4375 ед.), поэтому рисунок не скользит по полу;
- маховая нога идёт по плавной петле за телом и под ним; другая нога отстаёт на 4 кадра;
- руки качаются против ног по синусу, наклон корпуса 12°.

Результат: `run/run2-keypoints.json`, контроль — `run/run2-skeleton-preview.png` (линии земли и макушки стойки).
